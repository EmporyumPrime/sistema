# Emporyum System — publicação web

Endereço: **sistema.emporyumprime.com.br**

| Caminho | O que é |
|---|---|
| `/caixa/` | Emporyum System: caixa, café e pedidos, produtos e Clube. Para abrir a área da gerência, é preciso o código da direção. |
| `/admin/` | Emporyum Insights, o painel da direção. Abre só com o código de acesso. |

Esta é uma **prévia com dados fictícios**. Aqui ficam apenas os arquivos que já são servidos na web. O código-fonte está no repositório privado e esta pasta é gerada por `npm run publicar`, por isso não edite nada aqui à mão.

Não apague o arquivo `CNAME`: ele mantém o domínio no ar.
